# Investran — Base de Conhecimento de Sustentação

Este repositório reúne documentação técnica e operacional para manutenção e suporte do Investran.

## Objetivo

O foco desta base não é catalogar cada artefato existente, mas registrar **como localizar, entender, alterar, testar, depurar, publicar e recuperar** os componentes mantidos pela equipe.

## Fonte inicial

A documentação inicial de Active Templates foi baseada no **Developer's Guide to Active Template Manager**, aplicável ao Investran 6.2 SR3 e atualizado em 2011.

> **Atenção:** procedimentos específicos de ambientes, permissões, publicação, promoção entre bancos e operação da Goldman Sachs precisam ser confirmados durante o Knowledge Transfer. O material diferencia comportamento descrito pela FIS de informações ainda não validadas no projeto.
